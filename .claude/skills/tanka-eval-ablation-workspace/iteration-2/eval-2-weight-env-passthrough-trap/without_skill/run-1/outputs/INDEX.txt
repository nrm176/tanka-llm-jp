重要な注意点:
================================================================================

1. 環境変数は「シェル環境変数」で指定が最も確実
   → TANKA_W_REPEATED_WORD=12 docker compose up -d backend

2. 環境変数を「docker-compose.yml に明記」する方法も有効
   → ENV-VAR-PASSTHROUGH-GUIDE.md で詳説

3. eval.sh は SSH リクエストのみなので、ホスト側は LM Studio を起動しておく
   → lms server start (ホストの別ターミナル)

4. 結果の解釈は EXPECTED-RESULTS.md のパターンマッチで
   → 「repeated_word 違反が 2x 増加」「合格率 -8% 以内」等の基準で判定

5. 単一 run 同士の比較は sampling noise を含む可能性がある
   → 確実にしたければ eval-repeat.sh で variance 測定
