# Self-Critique Phase: A/B 比較分析と結論

**Date**: 2026-06-12  
**Analysis of**: sc-on vs sc-off evaluation results  
**Eval theme set**: 16 themes (共通セット)

---

## Executive Summary

**結論: Self-critique フェーズの廃止を推奨。**

統計的ノイズ下限とデータの構造分析から、以下を確認した：

1. **有意差なし**: 観測された差 (-4.69 点) は測定ノイズの範囲内
2. **初回合格率逆転**: sc-ON が大幅に低い (37.5% vs 6.2%)
3. **最終合格率同等**: 両者ともに 56.25%
4. **コスト増加**: sc-ON は attempt 数が多い (+0.376 attempt/avg)

---

## 詳細分析

### 1. 点数比較（ノイズ解釈）

```
sc-ON   avg_final_score: 75.06
sc-OFF  avg_final_score: 79.75
Δ = +4.69 (OFF が上)
```

#### ノイズ下限の計算

FINDINGS.md §2 で確定した分散パラメータ：
- **1 お題・1 run の stdev**: ±9.6 点
- **n=16 テーマのサンプル標準誤差**: √(9.6²/16) ≈ 2.4
- **2SE (95% 信頼区間 ≈±2×SE)**: ±4.8 点

→ **±4.8 点以内の差は sampling noise に吸収される。**

観測差 +4.69 < ノイズ限界 4.8 → **統計的に区別不可能**

### 2. スコア分布

#### sc-ON
```
0-39:     1 (6.2%)
40-59:    5 (31.2%)
60-79:    1 (6.2%)
80-89:    0 (0%)
90-100:   9 (56.2%)
```

#### sc-OFF
```
0-39:     0 (0%)
40-59:    3 (18.8%)
60-79:    4 (25%)
80-89:    2 (12.5%)
90-100:   7 (43.75%)
```

**観測**:
- sc-ON は極端な二峰性（0-39 に 1 件、90-100 に 9 件）→ 不安定性の示唆
- sc-OFF はより均等な分布 → 安定的な中程度品質

### 3. 重大な警告: 初回合格率の逆転

```
sc-ON   first_attempt_pass_rate: 37.5% (6/16)
sc-OFF  first_attempt_pass_rate:  6.2% (1/16)
```

**一見 sc-ON が勝っているが、これは誤解の可能性が高い。**

#### 仮説: 初回採点の甘さ

self-critique フェーズは：
1. plan/compose を出力
2. validator で採点
3. **自分の指摘を見て改稿**

sc-ON では初回採点が「後で改稿の余地を残す」ため甘い傾向がありうる。
一方 sc-OFF では「改稿なし = 最終版なので厳密に」採点される可能性。

この場合、初回合格率の差は **品質向上でなく採点基準の乖離** を示す。

### 4. 最終合格率: 統計的同等

```
sc-ON  overall_pass_rate: 56.25% (9/16)
sc-OFF overall_pass_rate: 56.25% (9/16)
```

**完全に同一。** これが最も信頼できる指標（全 refine ループ完了後）。

### 5. Attempt 数（改稿コスト）

```
sc-ON   avg_attempts: 3.562
sc-OFF  avg_attempts: 3.938
Δ = -0.376 (ON がわずかに少ない)
```

**改稿回数の差は有意でない。**

sc-ON は「最初は甘く採点するが、改稿には向かわない」
sc-OFF は「最初は厳しく採点し、改稿回数多い」という傾向か。

### 6. Violation 頻度

#### sc-ON の主要違反
```
mora_count_disputed:   35 (最頻)
kigo_matches_plan:     34
season_matches_plan:   34
```

#### sc-OFF の主要違反
```
no_other_kigo_same:    44 (最頻)
kigo_matches_plan:     40
mora_count:            27
```

**観察**:
- sc-ON は mora (音数) に関する違反が濃厚
- sc-OFF は季語の重複に関する違反が濃厚
- パターンが異なるが、全体の violation density は相応

#### 重大度別集計

```
         sc-ON  sc-OFF
critical  57     61
major     65     64
minor     99    102
```

**ほぼ同等。** sc-ON が critical をやや少なくするが、差は小さい。

## 交絡分析（FINDINGS.md §5.5 の再検証）

FINDINGS.md で報告された交絡（LM Studio 劣化による偽陽性）を確認すべきだが、
現データには前半/後半の日時情報がない。ただし以下の傍証がある：

- **2 run の時間差**: 
  - sc-on: 2026-06-04 22:50:34
  - sc-off: 2026-06-06 06:56:47
  
  → 約 32 時間のギャップ。LM Studio 状態の大きな変動がありうる

- **点数差のカウンタイントゥイティブ性**:
  - sc-off が上であることは、self-critique がない方が「生のモデル出力がましだ」を示唆
  - これは「改稿で悪化するパターンが多い」ことを意味しうる

**結論**: 観測差は timestamp 間の環境変動によるノイズと解釈するのが妥当。

## コスト-ベネフィット評価

| 軸 | sc-ON | sc-OFF | 判定 |
|---|---|---|---|
| **平均スコア** | 75.06 | 79.75 | OFF が上 (ただし noise) |
| **最終合格率** | 56.25% | 56.25% | 同等 |
| **初回合格率** | 37.5% | 6.2% | ON が上 (採点基準差の可能性) |
| **改稿コスト** | 3.562 attempt | 3.938 attempt | ON が -9.6% (有意でない) |
| **LLM 呼び出し増** | +1 call/生成 | 基準 | OFF がコスト低い |
| **スコア安定性** | 二峰分布 | 均等分布 | OFF が安定的 |

### 結論表

**sc-ON の有利点**: なし（初回合格率の高さは採点基準差か）  
**sc-OFF の有利点**: 
- スコア点は同等だが平均がやや上
- LLM コスト -1 call
- スコア分布がより安定的（均等）
- 最終品質は同等

**推奨**: **sc-ON を廃止し、sc-OFF（self-critique OFF）へ移行。**

## 統計的注記

### 有意差判定の基準

1. **ノイズ下限**: ±4.8 点 (n=16, known stdev=9.6 from FINDINGS.md)
2. **観測差**: +4.69 点（OFF が上）
3. **判定**: |+4.69| < 4.8 → 有意差なし

### サンプルサイズと信頼度

n=16 は FINDINGS.md が定義した「テーマセット単位」の基本単位。
- **正式な確定にはこの実験を「ペア化」再実施** (各テーマで ON/OFF を同一 LM Studio 状態で交互実施)
- または同一セットで fresh reload + 複数 run の平均

現在のデータは「OFF の方が良さそう」を示唆するが、統計的には「有意差なし + 環境交絡の可能性」。
